Навчальний довідник для тестувальників

Що це?

Неофіційний конспект із теорії тестування за структурою ISTQB Foundation (CTFL v4.0), клієнт-серверної архітектури, API testing та підготовки до співбесід. Проєкт не пов'язаний з ISTQB®.

⚠️ Застереження: Це неофіційні конспекти, написані власними словами. Проєкт не пов'язаний з ISTQB®. ISTQB® є зареєстрованою торговельною маркою.

Виберіть ваш рівень

👶 Junior

0–1.5 року досвіду

Розуміння термінів, основи тестування, перші кроки з автоматизацією API.

📖 ISTQB: Основи й терміни 🌐 Клієнт-сервер: HTTP, браузер, DevTools 🔌 API Testing: Перші API-тести 💬 Співбесіда: Типові питання

👨‍💼 Middle

1.5–4 роки досвіду

Застосування технік, самостійне проєктування, автоматизація, CI/CD.

📖 ISTQB: Застосування технік 🔐 Клієнт-сервер: Auth, кешування, CORS, БД ⚙️ API Testing: Автоматизація API 💬 Співбесіда: Архітектура & розробка

👨‍🎓 Senior

4+ років досвіду

Стратегія, управління, архітектурне мислення, менторство.

📖 ISTQB: Стратегія й управління 🏗️ Клієнт-сервер: Розподілені системи 🛡️ API Testing: Контракти, безпека, performance 💬 Співбесіда: Лідерство & стратегія

📝 Як користуватися

  1. Йдіть за рівнем: Спершу закрийте Junior повністю, потім переходьте до Middle. Senior читайте, коли вже маєте практичного досвіду.
  2. Чотири файли на рівень: Кожен рівень містить ISTQB-теорію, клієнт-серверну архітектуру, API testing і питання для співбесіди.
  3. Вправи & практика: Після кожного файлу виконайте практичні завдання на публічних API чи власному застосунку.
  4. Незнайомі терміни? Дивіться в глосарії.

⏱️ Орієнтовний шлях навчання

  • Тижні 1–4 (Junior): ISTQB розділи 1–6, HTTP, Postman. Мета: скласти CTFL-рівень знань і протестувати публічний API.
  • Тижні 5–12 (Middle): техніки на прикладах, автотести API, Playwright/Cypress, SQL, CI.
  • Далі (Senior): стратегія, метрики, архітектурне мислення, менторство.
