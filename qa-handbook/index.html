# QA Handbook Навчальний довідник для тестувальників: **теорія тестування за структурою ISTQB Foundation (CTFL v4.0)**, **клієнт-серверна архітектура** та **тестування API**. Матеріал розбитий на три рівні: Junior, Middle, Senior. > **Застереження.** Це неофіційні конспекти, написані власними словами. Проєкт не пов'язаний з ISTQB®. ISTQB® є зареєстрованою торговою маркою International Software Testing Qualifications Board. Для підготовки до іспиту користуйтеся офіційним силабусом і глосарієм на [istqb.org](https://www.istqb.org). Чинна версія силабусу Foundation Level — CTFL v4.0 (з обслуговуючими випусками, наприклад 4.0.1); іспит триває 60 хвилин і містить 40 запитань, прохідний бал 26 із 40. Умови іспиту й версію силабусу перевіряйте на сайті ISTQB, бо вони можуть змінюватися. ## Як користуватися 1. Йдіть за рівнем: спершу закрийте Junior повністю, потім переходьте до Middle. Senior читайте, коли вже маєте практику на реальних проєктах. 2. У кожному рівні чотири файли: ISTQB-теорія, клієнт-серверна архітектура, API testing, питання для співбесіди. 3. Після кожного файлу виконайте вправи «Практика» (вони є в кінці розділів) на публічних API чи власному застосунку. 4. Незнайомі терміни дивіться в [глосарії](glossary.md). ## Зміст | Рівень | ISTQB | Клієнт-сервер | API testing | Співбесіда | |---|---|---|---|---| | **Junior** (0–1.5 року) | [Основи й терміни](01-junior/istqb.md) | [HTTP, браузер, DevTools](01-junior/client-server.md) | [Перші API-тести](01-junior/api-testing.md) | [Питання](01-junior/interview-questions.md) | | **Middle** (1.5–4 роки) | [Застосування технік](02-middle/istqb.md) | [Auth, кешування, CORS, БД](02-middle/client-server.md) | [Автоматизація API](02-middle/api-testing.md) | [Питання](02-middle/interview-questions.md) | | **Senior** (4+ років) | [Стратегія й управління](03-senior/istqb.md) | [Розподілені системи](03-senior/client-server.md) | [Контракти, безпека, продуктивність](03-senior/api-testing.md) | [Питання](03-senior/interview-questions.md) | ## Що очікується на кожному рівні | | Junior | Middle | Senior | |---|---|---|---| | Фокус | Розуміти терміни й виконувати завдання | Самостійно проєктувати тести й автоматизувати | Визначати підхід, ризики, якість процесу | | ISTQB | Розділи 1–6 на рівні розуміння | Уміння застосовувати техніки, ризик-орієнтоване тестування, метрики | Test strategy, покращення процесу, управління, ROI автоматизації | | Клієнт-сервер | Запит/відповідь, HTTP, DevTools | Auth, кеші, CORS, черги, діагностика по шарах | Архітектурні ризики, відмовостійкість, observability | | API | Ручні перевірки в Postman/curl | Автотести, схеми, моки, CI | Contract testing, безпека, performance, стратегія | ## Шлях навчання (орієнтовно) - **Тижні 1–4 (Junior):** ISTQB розділи 1–6, HTTP, Postman.
